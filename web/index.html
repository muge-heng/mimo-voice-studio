欢迎来到 MiMo 语音工坊

开始之前，配置小米 MiMo 开放平台的 API Key —— 它只会保存在你的浏览器里。

①登录 MiMo 开放平台控制台，创建 API Key
②粘贴到下方（sk- 按量付费 / tp- Token Plan，自动识别）
③前往「设置」选择导出目录，生成音频即可自动落盘
④站点若已配置服务端密钥，可直接跳过本步
